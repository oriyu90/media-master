Media Masterは、写真・動画・音楽・書類・ストレージ・アプリを1つのアプリでまとめて管理できる、Android向けのオープンソースなメディア・ファイルマネージャーです。登録もアカウントも不要で、すぐに使い始められます。

端末の中身を、迷わず片づける。

写真や動画の閲覧から、音楽の再生、書類のスキャン、ストレージの整理、アプリ管理まで。必要な機能をひとつのアプリの中で行き来できます。

LIBRARY
写真・動画をアルバムで
端末内の全画像・動画をグリッド表示。保存先フォルダごとのアルバムビューにも対応し、タップでフルスクリーン再生・閲覧に進めます。
AUDIO
音楽をトラック・プレイリストで
Media3(ExoPlayer)によるバックグラウンド再生。フォルダ単位のプレイリストビューで、シャッフルやスキップも扱えます。
SCAN & DOCS
書類をスキャンしてPDFに
GMS Document Scannerと連携し、紙の書類をその場でPDFやJPEGへデジタル化できます。
MANAGE
ストレージとアプリを整理
内部/外部ストレージを直接ブラウジングし、カテゴリ別フィルタ、重複ファイルのハッシュ検出、インストール済みアプリ・APKの管理をまとめて行えます。
EDIT
簡易編集も手元で
画像のクロップ・回転、動画のトリムとミュートに対応(順次拡張中)。共有アクションもワンタップで呼び出せます。
BACKUP
スケジュールバックアップ
WorkManagerベースのバックアップエンジン。充電中やWi-Fi接続時のみなど条件を指定して、対象フォルダをZIPへ自動アーカイブします。

大画面では、Finder風のデスクトップUIに。

Android が DeX / デスクトップモードを返した場合、または表示幅が840dp以上の場合に自動で切り替わります。左サイドバーからホーム・ライブラリ・オーディオ・ドキュメント・管理・アプリ・設定へ移動でき、フォルダはドラッグ&ドロップでサイドバーへピン留めできます。

  • 内部ストレージ・外部ストレージ・ネットワークストレージの端末欄
  • Pictures / Download / apk を標準ピン留め
  • 長押しまたは右クリックで「新しいタブで開く」「ピン留め」「ピン解除」

今はソースからビルドして試せます。

Media Masterは開発初期(v0.1.0)のオープンソースアプリです。署名済みAPKの配布はまだ行っておらず、現時点はAndroid Studioでのソースビルドが入手方法になります。

ビルド手順

  1. 1GitHubリポジトリをクローンし、Android Studioで開きます。
  2. 2Android SDK 36 と JDK 21(ソース互換性はJava 11)を用意します。
  3. 3ターミナルで ./gradlew :app:assembleDebug を実行するか、Android Studioから実行します。
  4. 4生成されたdebug APKは app/build/outputs/apk/debug/ に出力されます。

READMEでビルド・署名の詳細を見る

対応OSはAndroid 7.0(API 24)以降です。メディアへのアクセスにはAndroid標準のMediaStore / Storage Access Frameworkを使用します。
